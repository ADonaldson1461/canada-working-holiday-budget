# WH HQ Research Engine — V6.9

The Research Engine monitors approved public sources, records evidence snapshots, detects changes, creates explainable review proposals and builds a read-only Research Command Centre. It does **not** silently change customer-facing data.

## Flow

Approved sources → fetch → normalise → snapshot → compare → intelligence → command centre → human review → canonical data → `build-data.py` → `data.js`

## Command Centre

Open `research/command-centre.html` from the deployed site to view source health, detected changes and pending research reviews. It is intentionally read-only. The page consumes `research/reports/command-centre-latest.json` generated by the engine.

## Safety rules

- Government/legal/tax/immigration changes require human approval.
- A source failure never becomes a data change.
- A detected page change is not automatically treated as a factual change.
- Canonical `/data` remains the publication source of truth.
- Research runs do not directly edit `data.js`.
- Every accepted baseline is timestamped.
- The Command Centre is an operational view, not an approval mechanism by itself.

## Local commands

```bash
python research/run_engine.py
python research/validate_data.py
python research/build_command_centre.py
```

The engine requires only Python's standard library. Network access is needed for source checks.
