# WH HQ V6.8 — Research Intelligence

V6.8 adds a deterministic intelligence layer on top of V6.7 source monitoring.

## What it does

1. Reads the latest source-change report.
2. Preserves the previous source snapshot and compares it with the current evidence.
3. Classifies a change into a research topic such as immigration, tax, wage, FX or transport.
4. Assigns severity using source criticality and evidence volume.
5. Maps the source to potentially affected WH HQ datasets.
6. Creates a review proposal with a bounded evidence diff.
7. Adds the proposal to the review queue without changing customer-facing data.

## Safety model

Research intelligence is proposal-only. It never edits `data.js`, never publishes a proposed value, and never treats a detected webpage change as proof that WH HQ data should change.

Critical immigration, tax and financial information remains human-approval-only.

## Local test

```bash
python research/validate_data.py
python research/watch_sources.py
python research/check_changes.py
python research/intelligence.py
```

The latest intelligence report is written to `research/reports/intelligence-report-latest.json`.

Pending proposals are stored in `research/review-queue.json`.

## Next stage

V6.8 intentionally stops before autonomous value extraction or publication. Future releases can add structured evidence extraction, richer dependency mapping and an admin review interface while preserving the same human-approval boundary.
