# V7.1 Work Hub — Acceptance Checklist

## Customer journey
- Work page opens without affecting Budget, Plan, Accommodation, Map or Guides.
- Destination can be changed.
- Job type can be filtered.
- Entry-level filter removes construction/office where experience is more likely to matter.
- Results use canonical `data.js` job and destination data.
- Wage ranges are displayed as planning benchmarks rather than guarantees.
- Minimum wage is shown for the selected destination.
- Job Bank opens externally.
- Budget Calculator link returns the user to the flagship tool.

## Product principles
- No job-placement claims.
- No invented live job listings.
- No additional customer account/login requirement.
- No customer payment flow.
- No new complex data-entry burden.
- Existing site navigation remains unchanged.

## Regression
- `budget.html` remains the flagship calculator.
- `data.js` remains the canonical browser data source.
- Research Engine files remain untouched by the Work Hub UI.
