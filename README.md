# Canada Working Holiday Budget Calculator — MVP

Open `index.html` in a browser to run it locally.

## Publish it
1. Create a GitHub account.
2. Create a new public repository, e.g. `canada-working-holiday-budget`.
3. Upload `index.html`, `styles.css`, and `script.js`.
4. Enable GitHub Pages in Settings → Pages → Deploy from branch → main.
5. Connect a custom domain later if desired.

## Important
The calculator uses illustrative cost assumptions. Replace them with your own research and date-stamp the assumptions. Immigration requirements should always be checked against the Government of Canada.
